This is an application-private implementation of the exact process-title call pair consumed by original macOS27 VZ. It does not register a process with system LaunchServices or provide a system-global/custom-runtime LSASN.

The original getter at VZ RVA `0x1916fc` is immediately forwarded as setter argument x1; the setter at `0x19171c` receives effective signed32 session -2, the imported CF string key, a real NSString title, and null fifth argument. Its return is not used. Genuine Mac getter returns a borrowed custom CF object; its Copy counterpart retains. Genuine setter forwards five arguments through dictionary construction, returns a low32 status (zero-extended by its inner w21 writes), and transfers a CF object's ownership through nonnull fifth output. That output's broader meaning is unproven, so this subset rejects nonnull output without writing it.

The provider returns a borrowed, stable, real CF dictionary containing actual PID, UID and a created per-process UUID. Only that exact object from this process may be passed back. This is provider-local identity, not the genuine ASN's runtime type or payload. The key's real Mac bytes are `LSDisplayName`. A supported setter copies the real string, retains its immutable snapshot under a mutex, and only then returns status zero. Invalid session, foreign identity, key, value or optional-output scope fails with signed32 -50. Allocation failure returns -108. No missing feature returns success, no foreign object identity is dereferenced, and fork-inherited identity cannot represent a new PID. Callers must supply valid live CF key/value objects.

`VM27CopyPrivateProcessDisplayName` exposes retained actual state to the frontend and diagnostics. The provider owns the process identity and latest name for its loaded process lifetime; replacing a name releases the previous one. A caller holding readback retains it independently. App title UI integration, arbitrary LaunchServices properties, nonnull-output semantics, original VZ execution and complete macOS27 loading remain separate work. No old macOS13 backend or iPadOS system database is imported or changed.
