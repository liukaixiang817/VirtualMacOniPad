# 独立 macOS27 后端的后续实现

当前优先级是让已连接 iPad 上的原始 macOS27 Virtualization/VMM 使用自有 CPU 后端启动真实来宾，并显示可操作的来宾画面。仅有静态依赖闭合、探针通过或框架加载，不构成启动验收。

首次可见启动配置明确使用零网卡、零音频设备。这个配置只是开发阶段；真实网络、22222 端口 SSH 和完整来宾可用性仍属于当前任务，不因列出本清单而取消。

可以在主启动链验证后补齐的功能：

| 功能 | 当前受限行为 | 后续工作与验证 |
| --- | --- | --- |
| macOS 显示服务、亮度、HDR headroom 和外接显示色彩空间 | iPad 使用自己的显示路径；没有兼容实现的服务请求明确失败，不伪造 Apple 服务对象或成功值 | 根据实际来宾调用补充 UIKit/CoreGraphics 实现，验证画面、色彩和显示变化 |
| IOSurfaceAccelerator 的新来宾转换命令 | Mac27 的 432 字节请求与当前 iPad16 的 368 字节接口不一致；未证实的转换明确返回“不支持”，不提交未知驱动数据 | 对比真实字段布局和版本能力，再实现安全转换；验证实际来宾图形请求及错误回退 |
| 音频输入和输出 | 首次启动配置不创建音频设备 | 接入原 Virtualization 音频端点与 iPad 音频会话，验证持续播放、录音和路由变化 |
| USB 主机和设备转接 | 尚无独立、已验证的转接实现 | 只针对明确设备建立真实接口，验证连接、断开和清理 |
| SVE、SME、AMX、嵌套 EL2/VHE 和扩展 CPU 能力 | 自有 CPU 能力配置不宣告尚未实现的功能 | 真实保存/恢复和执行支持完成后再宣告，验证迁移、异常和多 CPU 一致性 |
| 非必需插件安装与系统服务注册 | 缺少兼容实现的入口返回真实不可用错误 | 根据真实调用路径补充自有注册和生命周期，不冒充系统服务 |

启动前仍必须处理的工作包括：实际 CPU 状态访问和复位、计时器中断、最终签名运行包、真实父子进程身份与 IPC、磁盘启动、iPad 可见画面和输入。任何影响实际启动的上述延期项，应立即重新提升为阻塞修复。
