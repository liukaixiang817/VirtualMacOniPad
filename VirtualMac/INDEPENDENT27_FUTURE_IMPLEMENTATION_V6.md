# 独立 macOS27 后端：基本启动优先与后续实现

验收目标仍是：iPad 上运行真实来宾，全部使用独立 macOS27 Virtualization/VMM 与自有 CPU 后端；能够看到画面、使用基础键鼠，并通过 22222 端口以 lkx 登录。框架加载、CPU 创建或测试通过均不等于完成。

截至 2026-10-15 的实际进展：Runtime34/App45 已安装，真实创建四个不同 native CPU 槽位成功；AVP 控制器可以初始化。Normal36 仍在 CPU 初始化阶段断言退出，没有观察到真正 Run、来宾画面或 SSH。退出后的自有 App/子进程已清理。当前正在合并 ISAR2 初始化遗漏修复，以及依据同 CPU 实际特征省略未提供的 SCXT 状态；这两项尚未证明设备启动成功。

下列项目可以在基本启动和可用性完成后继续：

| 项目 | 当前范围 | 后续实现 |
| --- | --- | --- |
| HDR、外接显示及扩展色彩管理 | 优先 iPad 自有基本显示路径 | 完成真实显示服务和色彩能力适配 |
| 新版 IOSurfaceAccelerator 转换命令 | 未知接口保持明确不支持 | 根据真实布局、驱动能力实现转换和回退 |
| 音频 | 首次画面配置不创建音频设备 | 接入实际输入、输出和音频会话 |
| 外部物理 USB 及恢复连接 | AVP 外部连接保持 disconnected；保留虚拟控制器和标准键鼠 | 在真实可用的主机接口上实现连接、断开和恢复 |
| SVE、SME、AMX、嵌套 EL2/VHE | 不宣告未实现的 CPU 特性 | 实现真实执行、异常和完整状态管理后再开放 |
| FEAT_CSV2_2 / SCXTNUM | 正在接入创建 CPU 前明确不提供该可选特性的配置；按同 CPU 实际 PFR 决定状态片段是否存在 | 原生状态访问、来宾访问及完整保存恢复均实现后，再宣告此特性；不以 SYS 假成功替代 |
| 跨 CPU 配置的快照与迁移 | 不宣称跨特征配置兼容 | 实现状态有效性、配置及代际匹配和完整恢复 |
| 动态沙箱配置与非必需服务注册 | 保留真实不可用结果及自有进程身份校验 | 在支持的平台接口上接入真实隔离和生命周期 |
| macOS rawHID、媒体键及扩展输入 | 基础 USB 键盘和屏幕坐标鼠标属于当前主线 | 基础输入验证后补齐扩展事件 |

CPU 执行、RAM、GIC/计时器、磁盘启动、基本显示和输入、SSH 均不属于延期项。首次画面配置暂不创建网卡；这不能作为取消网络和 SSH 验收的理由。Main19/QGA7 的 SSH 路线目前仅完成 HOST 准备，仍需接入最终运行包并实际登录。

任何延期项一旦阻挡基本启动，应立即恢复为当前阻塞修复。此前 V5 等文件保留为历史记录，其中旧版本安装、审批和崩溃状态不代表当前设备状态。
