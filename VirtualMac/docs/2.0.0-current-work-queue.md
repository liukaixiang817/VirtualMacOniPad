The full27 settings currently retain disabled BC override and video acceleration
controls. BC execution exists, but the toggle is not connected to that provider;
the native host VideoToolbox endpoint remains unavailable. Mac keyboard choice
is currently USB-only on27. Apple Pencil pressure/tilt still requires the guest
helper and physical acceptance. These must not be hidden inside a general
"all settings implemented" claim.

Three-finger gestures are implemented through the native copied-contact route
and the user confirmed physical operation. Do not describe them as entirely
unimplemented. Four-finger mappings exist; each physical direction and both
backends still need explicit acceptance. Ordinary pointer/buttons, original
two-finger axes and scroll inversion must remain intact.

The backend selector has exactly two complete graphs: macOS13 and macOS27.
There is no silent fallback or mixed CPU/GPU mode. A visible toggle, capability
reply, successful microbenchmark or120Hz callback does not establish complete
guest or performance acceptance. Do not publish current unresolved GUI and
performance items as fixed.
