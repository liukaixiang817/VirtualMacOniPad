# VirtualMac 2.0.0 Beta 9（1009）

修复屏幕键盘点击“收起”后，再点来宾屏幕又自动弹出的情况。现在手动收起会同步清除键盘显示状态；点击来宾保持收起，再按一次工具栏键盘按钮即可重新打开。切换后台再返回后同样生效。

兼容的 macOS 27.2 及更新来宾新增默认启用的原生触摸屏，支持由 macOS 和应用处理的单指滚动、拖动、长按、双指缩放与旋转及多点输入。“设置 → 触控 → 原生触摸屏”可切换，更改后重启来宾生效。较旧系统和未识别构建保留原有输入方式。参考了 [Henge PR #32](https://github.com/Leviidev/Henge/pull/32) 的屏幕关联和触点生命周期经验；实现使用本项目已有的 Apple VZ 原生设备，无需在来宾安装触控插件。

本次在 M2 iPad Pro / iPadOS 16.1.1 上，使用最终 1009 安装包复测 macOS 26 和 27：手动收起、再次点击屏幕保持隐藏、一次按钮重新打开均通过；macOS 27 另外通过后台切换、软件键盘输入及点击来宾取得焦点后的硬件按键检查。测试输入已清空，没有提交来宾登录。

原生触屏的完整验收在此前未发布的 1008-2 开发候选包完成，包含五个同时触点、72/72 次连续点击、滚动、拖动、缩放、旋转、长按及后台释放与恢复。其触屏引擎目标文件与 Beta 9 字节一致；Beta 9 另通过原生触控菜单和正常关机检查。完整手势验收未在 1009 再跑一遍。详见 [实机验证记录](2.0.0beta9-device-validation.json)。

测试工具已删除，测试用的两个原有来宾均已正常关机。本次没有新建测试机，所有原有虚拟机和身份保留。

本版仍为测试版。此前原生触屏验收准备期间发生过一次来宾内核 panic，报告为 WebKit WebContent 进程中的内核链表损坏，回溯涉及 pthread；原因及其与触控的关系尚未确定。恢复后完成全部最终手势验收。真实手指的显示延迟、所有应用的触控行为及 macOS 27.2.1 尚未实机验证。

沿用 [Beta 8 修订版 1](2.0.0beta8-r1.md) 的安装版本推荐、完整版本列表和本地 IPSW 选择，以及 [Beta 8](2.0.0beta8.md) 的 Apple 账户支持与服务限制。CPU、恢复助手、无线和媒体载荷保持原样，本次没有新增 Apple 账户或消息服务测试。安装前正常关闭来宾并退出应用。

## English

Fixed the software keyboard reopening when tapping the guest after using the keyboard's Hide button. Manual dismissal now clears both the input surface and toolbar show request. The keyboard stays hidden on guest taps and reopens with one toolbar tap, including after backgrounding.

Compatible macOS 27.2+ guests now receive native screen touch by default, including application-controlled scrolling, dragging, press, pinch, rotation and multiple contacts. Settings → Touch provides a persistent Native Touchscreen switch; restart the guest after changing it. No guest touch helper is required.

The final Beta 9 package passed keyboard regressions on retained macOS 26 and 27 guests on an M2 iPad Pro running iPadOS 16.1.1. Additional macOS 27 checks covered background transitions, software input and hardware keys after guest focus. Full native gesture acceptance was performed on the preceding unreleased 1008-2 candidate, whose native touch engine object is byte-identical in Beta 9: five simultaneous contacts, 72/72 taps, gestures and background contact release/recovery passed. Beta 9 also passed a native power-menu touch smoke check. All temporary tools were removed, both guests shut down normally, and no new VM was created.

A guest kernel panic occurred during the earlier native-touch preparation, reporting a corrupt list in WebKit WebContent with pthread in the backtrace. Its cause and relationship to touch remain unresolved; full gesture acceptance passed after recovery. Physical-finger latency, every application's behavior and macOS 27.2.1 remain untested. Installer version choices and Apple Account support retain their previous coverage. Shut down guests and close the app before installation.
