# VirtualMac 2.0.0 Beta 9 RC2（1009-2）

修复新恢复镜像未列入旧 Build 白名单时，安装器跳过 Apple ID 身份生成的问题。现在所有新安装默认在恢复前生成独立身份、固定网络地址和兼容选项，并绑定 Apple 创建的原生机器身份。已有身份继续沿用。

安装版本选择器现在每次打开读取 [Apple 官方恢复目录](https://mesu.apple.com/assets/macos/com_apple_macOSIPSW/com_apple_macOSIPSW.xml)，并合并 VirtualBuddy 历史目录。支持刷新按钮、下拉刷新及版本号/Build 搜索，取消固定最大 macOS 版本的过滤。苹果提供新 Mac IPSW 后，可在“选择其他 macOS 版本”中刷新并选择；离线版本、已验证推荐和本地 IPSW 入口保留。

增加 `27.2.1 / 26B131` 的内核审核记录，其相关内核代码与已审核的 `26B123` 字节一致。所有有效新 Build 均生成身份；未知内核不使用猜测的注入偏移。新版本出现在列表、成功生成身份，不代表该系统或 Apple 服务已经验收通过。

最终 RC2 已安装到 M2 iPad Pro / iPadOS 16.1.1，15 个变更组件的实机哈希读回一致，现有四台来宾元数据保持一致。安装准备、目录和触控目标文件与先前实机检查的功能候选包字节一致：在线 27.2.1 的显示、版本号搜索和刷新已通过；实际产品 API 对元数据合成的未来 Build 在两种后端选择标记下均生成身份。没有创建测试虚拟机。

按用户要求跳过 27.2.1 的后续 Apple ID 登录测试，本版不宣称该版本账户认证已通过。已停止来宾并清理本轮探针、检查点和已完成安装的临时文件，保留现有虚拟机及安装介质。沿用 [Beta 9](2.0.0beta9.md) 的键盘修复、原生触屏及已披露限制；本次未重新进行完整触控或消息服务测试。安装前正常关闭来宾并退出应用。

## English

Every new restore now receives a persistent, independent Apple Account identity and compatibility settings before installation, including builds outside the previously audited list. The real Apple-generated machine identity is preserved and bound to the profile.

The installer refreshes Apple's official restore catalog alongside VirtualBuddy history. Refresh, pull to refresh, and version/build search are available; future major versions are no longer hidden by a fixed maximum. Verified recommendations, offline choices and local IPSW import remain available. Visibility and identity preparation do not establish compatibility with untested future operating systems or Apple services.

Added audited kernel coverage for 26B131. The final 1009-2 package was installed on an M2 iPad Pro running iPadOS 16.1.1; all 15 changed component hashes matched and all four retained guests were preserved. The functional candidate passed live 27.2.1 discovery/search/refresh and actual preparation API checks using synthetic future-build metadata. Its preparation, catalog, CPU and touch components match RC2. No new VM was created. Further macOS 27.2.1 account authentication tests were skipped at the user's request and are not claimed as passed. Temporary device tools, checkpoints and completed restore extraction were removed. Beta 9's touch/keyboard validation and known limitations still apply.
