# VirtualMac 2.0.0 Beta 8 (1008)

Beta 8 将 Apple ID（Apple 账户）支持固化到 deb。使用默认的完整 macOS 27 后端新建受支持来宾时，应用在恢复前自动生成并保存每台来宾独立的身份，第一次进入 OOBE 设置助理即可登录 Apple ID，并正常完成 Apple 双重认证。无需先进入桌面、安装 Guest Tools 或通过 SSH 手动启用。

支持审核过的恢复构建：macOS 15.6.1 `24G90`、macOS 26.6.2 `25G83`、macOS 27 `26A5416b` 和 macOS 27.2 `26B123`。其他构建需要单独适配。15、26、27.2 的功能候选版已实际完成 Apple 账户认证并在正常冷启动后保留；27.2 另验证了正式候选包从空盘恢复到首次设置中的短信认证。27 `26A5416b` 已验证身份与进程处理并到达 MFA，未计为完整账户登录通过。

- 身份与固定网络地址随每台来宾持久保存，恢复结束和后续冷启动沿用同一份数据。现有来宾的原身份保持不变。
- 保留 Beta 7 的 Wi-Fi、蓝牙设备发现、摄像头、麦克风、扬声器，以及可选的 macOS 13 后端；Apple 账户兼容功能使用完整 27 后端。
- 正式 App 移除了实验操作入口；包名和 Bundle ID 仍为 `com.mac.virtual.independent27`。deb 不包含来宾磁盘、已登录账户、密码或验证码。
- 安装前正常关闭来宾并退出 VirtualMac。新建来宾需要 [Virtual Mac 1.2.4 安装助手](https://github.com/nfzerox/VirtualMacOniPad/releases/tag/1.2.4)，deb 已声明精确版本依赖。宿主实机验收为已越狱 M2 iPad14,6、iPadOS 16.1.1（20B101）。

App Store 已在 15、26、27.2 实际下载并启动应用；iCloud Drive 上传、下载及跨来宾内容哈希核对通过，其中 15、26 后续新增文件的目录刷新需要正常重连云盘。邮件已在 IMAP 服务器“已发送”中确认，收件端尚未验收。iMessage 在 27.2 使用获授权的对照账户完成一次真实投递并由另一台 Mac 收到，但原测试账户的激活问题仍未解决；FaceTime 尚未验收。Apple ID 登录支持不代表所有账户都能通过 iMessage 或 FaceTime 激活。

Beta 8 从已发布的 Beta 7 正式 App 集成账户功能，账户模块、恢复助手和 CPU provider 沿用已通过实机验收的实现；发布包通过签名、解包文件哈希、权限和实验入口缺失检查，并已在目标 iPad 通过 deb 正常安装，全部 14 个变更组件均与打包内容一致。Beta 8 实机正常冷启动后，macOS 27.2 的持久身份、固定 MAC 和 Setup Assistant 进程策略也重新回读通过。账户实现与构建入口见 [Apple 账户兼容实现](../apple-account-v1.md)，实际验收范围见随发布提供的 JSON。

## English

Beta 8 enables Apple Account sign-in during Setup Assistant for newly created guests on the default complete macOS 27 backend. Each supported restore receives a persistent, independent identity before installation and its first boot. No desktop, optional Guest Tools or manual SSH setup is needed. Apple two-factor authentication remains part of the normal sign-in flow.

Audited restore builds are `24G90`, `25G83`, `26A5416b` and `26B123`. The feature candidate completed real Apple Account authentication and cold-boot persistence on macOS 15, 26 and 27.2; `26A5416b` reached MFA and is not counted as fully authenticated. Beta 7 radio/media features and package identifiers are retained. Shut down guests normally before upgrading. The Virtual Mac 1.2.4 installer is an exact package dependency. The tested host is a jailbroken M2 iPad14,6 running iPadOS 16.1.1 (20B101).

App Store downloads, iCloud Drive content transfers and IMAP server-side sent-mail records were verified on 15, 26 and 27.2. Later incoming Drive metadata on 15/26 required a normal reconnect. A macOS 27.2 alternate-account iMessage delivery was confirmed on another Mac; the original test account still has an activation issue, and FaceTime has not been accepted. Account sign-in support does not guarantee activation of every Apple service for every account.

Apple Account identity and process-policy design is adapted from the supplied Henge Build 104 reference. The VZ restore integration, native runtime and per-guest persistence are implemented in this project.
