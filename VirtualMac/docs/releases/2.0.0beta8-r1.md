# VirtualMac 2.0.0 Beta 8 修订版 1（1008-1）

新建虚拟机现在明确推荐 macOS 15.6.1、26.6.2 和 27.2，并显示已验证的 Apple ID 登录支持。推荐版本保存在签名安装包中，在线目录不可用时也能直接选择。

“选择其他 macOS 版本”可浏览具体版本、构建号、正式版或测试版以及 Apple ID 验证状态。在线目录当前提供的 27.2.1 仍可自行选择，标记为 Apple ID 登录尚未验证；27.2 保持已验证标记。“选择自定义 IPSW”允许导入 Apple 镜像，安装列表以外的版本。开发者测试版仍可通过筛选菜单显示。

此次改动不扩展未验证构建的 Apple ID 兼容范围。[Beta 8 的服务验证范围与限制](2.0.0beta8.md)仍然适用。沿用 Beta 8 的账户、身份、CPU 与恢复实现，以及已有无线和媒体功能。安装前应关闭运行中的来宾并退出应用；宿主实机范围及原恢复助手依赖与 Beta 8 相同。

验证：原生目录逻辑测试及实机推荐页、其他版本列表检查通过。在 iPad14,6 / iPadOS 16.1.1 上，15.6.1（推荐入口）和 27.2（完整列表手动选择）均完成空盘恢复安装并启动至首次设置。两者的 Apple 账户身份均在恢复前建立，构建配置及机器标识绑定匹配。两台临时测试机及安装残留已删除，原有虚拟机保留。本次未重复 Apple 账户、短信或 iMessage 服务测试。

## English

The installer now recommends macOS 15.6.1, 26.6.2 and 27.2, with explicit Apple Account verification labels. These signed, bundled recommendations remain visible when the online catalog is unavailable; downloading a restore image still requires a connection. Choose another version to browse full releases and optional developer betas, or import a local Apple IPSW. Newer unverified releases remain selectable without inheriting a verified Apple Account label.

Apple Account compatibility and the existing runtime, radio and media implementations are unchanged from Beta 8. This update does not claim Apple Account support for unverified builds such as 27.2.1. Shut down guests and close the App before installation.

Validation: fresh empty-disk restore and first boot to Setup Assistant passed on macOS 15.6.1 and 27.2, using the recommended and manual version-list routes respectively. Both disposable guests and their installation attempts were removed after testing; existing guests were retained. Account and messaging service tests were not repeated. See [device validation](2.0.0beta8-r1-device-validation.json).
