# VirtualMac 2.0.0beta6-r1 (1006.1)

This revision fixes the missing independent SpringBoard gesture companion and
adds a full-screen frosted-glass overlay while the guest is paused.
The Debian package version is `1006-1`, which upgrades `1006`.

## Independent gesture behavior

The original Beta6 deb omitted the SpringBoard companion. The development
machine retained it from an earlier installation, so working gestures on that
machine did not establish clean-install behavior. The revision includes its own
`VM27GestureGuard` companion, filter, signature and trust registration. It does
not replace the1.2.3 companion or require1.2.3 to be installed.

The existing Ignore iPadOS System Gestures and Ignore iPadOS Multitasking
Gestures switches remain independent. Suppression requires the independent App
to be frontmost, its VM display to be active, a live App-owned marker, and an
unlocked screen. Startup, lock screen, other applications and leaving the guest
retain native behavior. Private method signatures are checked before hooking;
unavailable methods retain system behavior. Existing guest three/four-finger
mapping and two-finger scrolling are unchanged.

## Pause presentation

A paused guest is covered by a full-screen UIKit material blur with a pause
indicator and Resume button. The overlay blocks guest touches and follows the
real VM state. Saving a Hibernate session updates the status and disables
Resume until the operation finishes. The blur is removed after native resume;
it does not add a permanent backdrop-rendering pass while the guest runs.

## Install

Shut down the guest and close VirtualMac before installing
`VirtualMac_2.0.0beta6-r1_1006-1.deb`. Then restart SpringBoard once to load the
new companion. Sileo receives the restart action; command-line installs print
the same instruction and do not restart the shell unexpectedly. Dopamine's
normal ElleKit injection must be enabled. Both complete backend runtimes remain
bundled, and guest disks and settings are preserved.

Enable the existing two gesture switches in VirtualMac Settings if desired.
The switches are opt-in; this update does not overwrite the user's choices.

## Validation scope

The exact deb was installed on M2/iPadOS16.1.1. With the old companion filter
removed before the shell restart, the new component installed all four native
gesture hooks and reached its post-launch guard. A full27 cold boot reached the
desktop. Native pause/resume completed successfully; original iPad screenshots
show the full-screen blur and its disabled Resume button while saving. Guest
SSH22222 and Apple HTTPS200 passed after resume. Host fixtures checked lock,
startup, foreground identity, independent switches and marker lifetime; those
fixtures are not physical gesture delivery tests.

The final validation record accompanies this release. M1 physical gesture
acceptance remains separate from the available M2 test machine. USB passthrough
is postponed. Existing Beta6 GPU, audio and performance limitations remain;
this revision does not claim to fix them.
