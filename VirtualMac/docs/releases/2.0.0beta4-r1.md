# Beta4 revision 1 — package 1004-1

This revision fixes two fresh-device startup/installation defects in the original Beta4. It retains App build 1004 and both complete backends. The Debian revision is 1004-1 so package managers can upgrade 1004 in place.

## Failure and repair

An M1 iPad on iPadOS 16.1.1 reported `Owned child startup failed (13)` before `posix_spawn`, while dpkg reported `half-configured`. No OS crash reports were present in that diagnostic archive.

The App previously opened its log with `freopen(..., "a")`. On a new device the file could inherit 0644 permissions and the temporary directory's group, but the existing child-launch contract requires a single-link regular file owned by mobile:mobile with mode 0600. App248 opens the file without following symlinks, checks ownership/type/link count, normalizes its own group and mode through the open descriptor, and connects both append descriptors to the same file. Existing bytes are preserved; child identity and descriptor checks remain intact.

The package installer also called `ldid` without declaring a dependency. The reported package inventory has no ldid. The repaired installer verifies the full signed-file SHA256 bound to each CDHash at package build time, uses Dopamine's existing `jbctl`, and confirms the hashes are present before declaring configuration complete. It does not install a signing utility or alter kernel checks. Configuration phases and errors are saved locally; the diagnostic ZIP now includes that log and stdout/stderr metadata.

## Install and report

Normally shut down the guest and close VirtualMac, then install `VirtualMac_2.0.0beta4_1004-1.deb`. This is a complete package, including both runtimes; no manual chmod, signing command or dependency on 1.2.3 is required. Existing guest disks/settings are retained. A previous half-configured package can be upgraded with this revision.

If a failure remains, reopen the App and export diagnostics again. Include the model, system build, Dopamine version, backend and reproduction steps in this repository's Issues. Review private paths/network details before sharing; nothing uploads automatically. The original user's diagnostic archive is not part of the release.

The existing experimental Dopamine iOS/iPadOS15–16.3.1 hardware scope and unfinished features remain as documented in [Beta4](2.0.0beta4.md). The final revision's device-validation attachment distinguishes reproduction, recovery and tests from unverified combinations. The report device itself was not connected to the developer Mac.

## Validation of the final deb

On the connected M2 / 16.1.1 / Dopamine 2.4.8 device, old Beta4 reproduced the exact error 13 with a mobile-owned log inheriting group wheel and mode 0644. Installing the final complete 1004-1 deb took about 14 seconds and completed dpkg configuration. App248 repaired the same file to mobile:mobile 0600 without deleting its contents; both descriptors passed the child contract and posix_spawn succeeded. The full macOS27 backend booted the existing macOS26.6.2 guest, authenticated SSH through iPad port 22222 and returned HTTPS200 from apple.com. A native USB screenshot verified the awake login page with wallpaper and cursor. The report's M1 device was not available for physical retesting.

The final installer performs one bulk file check and one manifest binding check, avoiding repeated per-image hashing and trust-list subprocesses. Local tests cover missing ldid, retry idempotence, corrupted files, mismatched hash bindings and an unregistered hash despite a successful jbctl exit. The networking source archive was actually relinked successfully.

Standard rootless Dopamine is the default. Both runtime trees, host compatibility code, networking libraries and guest helper resources are included; Dopamine's own bootstrap tools and trust service remain prerequisites. Existing runtime/display/input bytes are retained, including the prior cursor activity refresh fix. This revision does not claim fresh physical testing of every admitted hardware/OS combination or completion of the earlier advanced-feature backlog.
