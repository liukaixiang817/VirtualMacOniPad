# VirtualMac 2.0.0 Beta 8 修订版 2（1008-2）

兼容的 macOS 27.2 及更新来宾现在默认使用原生触摸屏。手指点击、单指滚动与拖动、双指缩放与旋转、长按及多点输入由 macOS 和应用处理。应用“设置 → 触控”新增“原生触摸屏”开关，更改后重启来宾生效。较旧系统和未识别构建保留原有输入方式。

参考了 [Henge PR #32](https://github.com/Leviidev/Henge/pull/32) 的屏幕关联和触点生命周期经验；本项目使用已有 Apple VZ 原生触屏设备，无需在来宾另装触控插件。键盘、鼠标、触控板及 Pencil 沿用原有通道。新安装流程保存系统构建号，供首次启动选择适用输入方式。

在 M2 iPad Pro / iPadOS 16.1.1 / macOS 27.2（26B123）上，设备端触点注入经真实 UIKit、VZ 与 AppKit 路径验证了原生触屏能力、五个同时触点、72/72 次连续点击、单指滚动拖动、双指缩放旋转、长按及后台释放和恢复。设置开关保存与正常关机通过；临时探针已删除，所有原有虚拟机保留，本次没有新建测试机。详见 [实机验证记录](2.0.0beta8-r2-device-validation.json)。

本版仍为测试版。最终回归准备期间观察到一次来宾内核 panic，报告为 WebKit WebContent 进程中的内核链表损坏，回溯涉及 pthread；原因尚未定位，与触控的关系未确认。恢复后完成上述全部最终测试。真实手指的显示延迟、全部应用的触控行为及 macOS 27.2.1 尚未实机验证。

沿用 [修订版 1](2.0.0beta8-r1.md) 的安装版本推荐、完整版本列表和本地 IPSW 选择，以及 [Beta 8](2.0.0beta8.md) 的 Apple 账户支持及服务限制。CPU、恢复助手、无线和媒体载荷保持原样；本次不扩大 Apple 账户验证范围，也未重做短信或消息测试。安装前正常关闭来宾并退出应用。

## English

Compatible macOS 27.2+ guests now use an original Apple virtual touchscreen by default. Native screen contacts enable application and macOS touch interactions, including single-finger scrolling and dragging, pinch, rotation and press. App Settings → Touch provides a persistent Native Touchscreen switch; restart the guest after changes. Existing keyboard, pointer, trackpad and Pencil routes are retained.

Device-side HID injection on an M2 iPad Pro running iPadOS 16.1.1 and macOS 27.2 validated the real UIKit → VZ → AppKit path: native screen capability, five simultaneous contacts, 72/72 repeated taps, gesture recognition and contact release/recovery after backgrounding. Temporary test tools were removed; existing guests were retained. No new guest was created for these tests.

This remains a prerelease. A guest kernel panic occurred during final preparation, reporting a corrupt kernel list in WebKit WebContent with pthread in the backtrace. Its cause and relationship to touch remain unresolved; all final acceptance tests passed after recovery. Physical-finger latency, every application's touch behavior and macOS 27.2.1 were not tested. Apple Account compatibility is unchanged from Beta 8. Shut down guests and close the App before installation.
