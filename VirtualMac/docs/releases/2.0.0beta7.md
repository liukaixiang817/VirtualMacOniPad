## VirtualMac 2.0.0 Beta 7

Beta 7 为新建的 macOS 15、26 和 27 来宾集成 Wi‑Fi、蓝牙设备发现、摄像头、麦克风和扬声器，并保留可选的 macOS 13 和独立 macOS 27 后端。

- 摄像头在 Wi‑Fi／蓝牙的首次管理员授权流程中一并配置。悬浮菜单「强制关机」下方可共享摄像头并在 480p、720p、1080p 之间切换，也可控制麦克风和扬声器。
- 扬声器默认开启。共享麦克风的选择在来宾下一次冷启动时生效。系统隐私权限照常请求。
- 安装 `VirtualMac_2.0.0beta7_1007.deb` 前，请正常关闭运行中的来宾并退出 VirtualMac。使用官方恢复镜像创建新来宾需要 [Virtual Mac 1.2.4 的安装助手](https://github.com/nfzerox/VirtualMacOniPad/releases/tag/1.2.4)。宿主无线组件支持已越狱的 M2 iPad14,6，系统为 iPadOS 16.1.1（20B101）。

| 通过空盘安装验证的来宾 | 构建 |
| --- | --- |
| macOS 15.6.1 Sequoia | `24G90` |
| macOS 26.6.2 Tahoe | `25G83` |
| macOS 27 Developer Beta 6 | `26A5416b` |

实机功能候选版在三个构建上验证了首次配置、独立 Wi‑Fi、主客机不同热点并发 HTTPS、蓝牙设备发现、摄像头三档切换及实际音频输入输出。macOS 27 第一次在传输数据页停顿，第二次从空盘安装顺利完成。冷启动最早的联网探测出现过失败，随后均自动联网并连续通过 HTTPS。Beta 7 的公开 App 移除了测试入口并更新了签名和版本。三个来宾包、摄像头助手、iPad 无线服务和两套运行时均沿用通过验收的文件。Beta 7 DEB 已通过解包签名和隔离安装脚本校验，复打包摘要一致。

### English

Beta 7 adds native Wi‑Fi, Bluetooth device discovery, a switchable 480p/720p/1080p camera, microphone input and speakers for new macOS 15, 26 and 27 guests. Open the floating menu below **Force Shutdown** to configure media. Microphone changes take effect on the next cold boot. Official restore-image installation uses the helper from Virtual Mac 1.2.4. The included host radio services target jailbroken iPad14,6 on iPadOS 16.1.1 (20B101).

The feature candidate passed real-device fresh installation and hardware checks on all three builds listed above. The public App removes laboratory entry points and updates the version and signature. Beta 7's guest components and radio services are byte-identical to the validated payload. Its package and Debian maintainer scripts passed local verification. Camera device code is adapted from [Henge PR #100](https://github.com/Leviidev/Henge/pull/100).
