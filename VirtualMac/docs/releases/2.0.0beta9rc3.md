# VirtualMac 2.0.0 Beta 9 RC3（1009-3）

为 macOS 27.2.1 / 26B131 增加内置 Wi-Fi、蓝牙和首次配置包。该构建的无线接口比此前的 27 增加了一个虚函数槽，不能直接复用旧驱动；新包使用其实际内核和蓝牙程序审核得到的独立配置。原有 24G90、25G83、26A5416b 的常规包、自动包和目录项保持逐字节一致，本轮没有启动或复测这些系统。

修复 DEB 升级后无线服务仍占用旧程序文件的问题。即使程序内容不变，安装器替换文件也会使旧进程的程序路径失效，导致正常身份校验拒绝连接。现在安装前检查并停止项目自己的两个服务，安装完成后先由原有助手校验自有无线会话并正常结束旧连接，再重新注册；身份和路径校验继续保留。

27.2.1 的配置流程改为正常关机、等待完整后端释放，再冷启动同一来宾，避免原地重启停在黑屏。菜单增加相同的 Restart 入口。首次后台启动较慢时继续显示配置进度；所有者授权界面明确说明第三方扩展以及 kext、文件系统、调试、NVRAM 四项来宾保护调整，并保留已认证根目录保护。

实机验证限于 M2 iPad Pro / iPadOS 16.1.1 上的现有 27.2.1 来宾：原生 Wi-Fi 获取 DHCP 地址，绑定无线接口的 HTTPS 返回 200；正常冷启动后自动恢复。原生蓝牙控制器开启并发现附近设备，未验证实体设备配对。完整 27 后端下，原生玻璃视图、Dock 动态重绘和两种 GPU 纹理格式的颜色回读通过，未复现所报的白块、黑块或错色；这不能证明所有应用的渲染路径均无问题。

本版沿用 RC2 的安装前独立 Apple 账户身份生成、实时恢复目录、版本搜索及 Beta 9 的触屏和键盘修复，本轮没有重新测试 Apple 账户认证。无线适配仍按已审核的精确构建选择，不能把未来版本出现在安装列表理解为无线驱动已兼容。首次配置需要正常完成 macOS 设置和本地所有者授权。

安装前正常关闭来宾并退出应用。27.2.1 请使用「VirtualMac 2 beta9」启动。现有来宾保持保留；本轮仅清理自有临时探针和检查点。

## English

RC3 adds a build-specific, bundled radio and first-run setup package for macOS 27.2.1 (26B131). Its native Wi-Fi ABI differs from the previously supported macOS 27 build. Existing packages and catalog entries for 24G90, 25G83 and 26A5416b remain byte-identical and were not retested in this round.

Package upgrades now stop the verified project-owned radio services before replacing their executables, including identical-content updates. The existing identity-checked recovery helper retires the old owned station session before service registration. This prevents stale executable paths from failing peer authentication. The audited 27.2.1 setup uses normal shutdown, complete backend teardown and a cold start of the same guest. Owner authentication explains the required guest policy changes; authenticated-root protection is retained.

Physical-device validation on the retained 27.2.1 guest passed native Wi-Fi DHCP, interface-bound HTTPS and automatic reconnection after a cold start. Native Bluetooth discovered nearby devices; physical pairing was not tested. Native glass, dynamic Dock redraw and GPU color readback passed on the complete macOS 27 backend without reproducing the reported blocks. This does not establish correctness of every application rendering path. Apple Account authentication was not retested. Future catalog visibility does not establish future radio compatibility.
