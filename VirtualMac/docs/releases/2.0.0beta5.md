# VirtualMac 2.0.0beta5 (1005)

Complete macOS13 and complete independent macOS27 remain the only backend choices.
This package supersedes Beta4-r1 and includes the completed development implementation
from App274/Runtime174, plus the App275/Runtime175 portability fix.

## Fresh-device startup and installation

The M1 /16.1.1 /Dopamine3.0.10 report contained a reproducible path admission failure:
the cache helper still compared the App with a developer-device preboot path. It now
resolves the stable `/var/jb/Applications/VirtualMacIndependent27.app` installation,
checks the actual regular file, owner and inode, and retains the caller/framework
and signed-runtime identity checks. Native libc is identified through its actual
loaded export instead of a single host-build UUID and RVA. The installer creates
the two private mobile-owned cache directories on a clean device.

The reported package was half-configured at trust-cache enumeration, exit127.
The original underlying stderr was missing, so its exact failure remains unknown.
The installer now executes canonical Dopamine basebin/jbctl and preserves stderr.
Enumeration is optional: if unavailable, every pinned owned hash must receive a
successful native add result, as in upstream1.2.3. An add failure still aborts;
there is no fake trust result, global trust clear, bundled replacement jailbreak
core, or skipped manifest validation.

Compared sources: upstream tag1.2.3, commit046abc6e0a5d16a20e53d175db98ba5c6f6471b6;
`VirtualMac/packaging/DEBIAN/postinst`, `vz/host/vzxpchook.m` and
`vz/host/installationhook.m`. Upstream uses stable paths, version/ABI variants
and direct native trust registration. Its broad cache interposition is not needed
for the new parent-only cache adapter.

## Included development features

- Native persistent Hibernate for full27: memory/device save, durable commit,
  stop/free, process death and reopening the App to restore the saved session.
  Background save and Saved Session/Resume/discard controls are included.
- CPU98/GIC19 saved-state serialization and read-only native input handling;
  MD27 terminates native VT sessions through a real availability/error boundary.
- GPU24 BC texture upload/view improvements, basic WebGPU/f16/indirect compute
  and static Metal shader stitching paths, with bounded execution coverage.
- Scoped guest OpenGL compatibility and native microphone capture improvements.
- Retained three-finger gestures, two-finger axes/inversion, pointer/drag fixes,
  ProMotion callback scheduling, lock-pause, SSH controls and text clipboard.

## Installation

Download `VirtualMac_2.0.0beta5_1005.deb`. Shut down the guest normally and close
the App before upgrading. Resume and shut down any saved session before changing
runtime versions. Install through the existing Dopamine package manager; disks
and settings are retained. Complete runtime graphs, network libraries and guest
helper resources are included. The old1.2.3 package and extra ldid are not required.
A working standard rootless Dopamine bootstrap is required.

## Validation and remaining work

The final deb passed actual install/configure from an absent private cache on an
M2 iPad /16.1.1 /Dopamine2.4.8, then full27 guest boot, native login-wallpaper
capture, authenticated SSH through iPad22222 and Apple HTTPS200. Hibernate final
package results are recorded in the accompanying device-validation.json.

The reporter's M1/Dopamine3.0.10 is not physically connected for retesting.
M1/M2 iPads and A16 iPhone14 Pro/ProMax on Dopamine15–16.3.1 remain experimental;
this does not certify the full hardware/OS matrix. iOS14, rootful and roothide
are outside this package's scope.

Settings/Dock missing icons and occasional animation stutter are still open.
120Hz callback cadence is not a guarantee of120 physical frames per second.
Bluetooth is deferred independently of audio. Sustained microphone/playback,
physical speaker output, all four-finger directions, non-text clipboard, clean
IPSW installation, guestIPv6 and bridged networking remain unaccepted or unfinished.
Native host video encoding, mesh/ray tracing/dynamic libraries and full Safari
feature parity are not complete. See the current work queue for exact boundaries.

Hibernate needs sufficient storage for guest RAM and the device unlocked while
writing its native Keychain-protected state. Locking pauses the VM; SIGKILL before
a completed save cannot preserve newer RAM. Saved state is consumed before resume
so stale RAM cannot silently be replayed against an advanced guest disk.

Export Diagnostics from Settings on failure and inspect private information before
sharing it. The user's original diagnostic ZIP is not part of the public release.
