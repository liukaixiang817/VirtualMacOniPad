# VirtualMac 2.0.0beta6 (1006)

Beta6 fixes a graphics capability error affecting M1, merges the completed App
re-entry and CPU wake optimizations, and removes the installer's optional `awk`
dependency. Physical USB-C passthrough is deferred to the next release.

## Graphics compatibility

The reported M1 / iPadOS16.1.1 log returned false for framebuffer reads because
the adapter queried only Apple8. M1 is Apple7. When the native macOS getter is
absent, the adapter now queries the actual device for Apple2, Apple's documented
minimum for programmable blending/framebuffer fetch. Native getters, caller
validation, GPU execution and other capability answers remain intact.

References: [Apple GPU families](https://developer.apple.com/documentation/metal/mtlgpufamily/apple7)
and [Metal feature tables](https://developer.apple.com/metal/feature-sets/).

This corrects the false capability observed in the reporter's log and targets
corrupted translucent menu backgrounds. The connected test device is M2, not
the reporter's M1: exact reproduction and physical M1 acceptance are not claimed.
The negative-control test forced the old false answer on M2; its black screen
observation overlaps display-wake behavior and is inconclusive for the reported
colored corruption. The released package contains only the native capability
query, never that diagnostic override.

## Completed development merged

- App279 lifecycle fix: an App that only opened Settings, then went to the
  background, can reconstruct an exited backend connection when reopened.
  This also covers re-entry after a committed Hibernate session.
- CPU99: remove repeated mapping queries for an admitted cross-CPU wake read,
  retaining owner/lifetime validation and the generic fallback.
- Retain full13/full27 selection, persistent Hibernate, gestures, pointer
  scheduling, ProMotion settings, IPv4 NAT, SSH forwarding and text clipboard.
- Retain the GPU, OpenGL and audio development already included in Beta5.

## Installation

Download `VirtualMac_2.0.0beta6_1006.deb`. Resume any saved session using its
existing version and shut down the guest normally, then close VirtualMac before
upgrading. The changed graphics capability requires a cold boot; saved RAM from
another runtime is not silently accepted. Guest disks and settings are retained.

Both complete backend graphs, network libraries and guest helpers are included.
The old1.2.3 package and an extra `awk` or `ldid` installation are not required.
A standard working rootless Dopamine bootstrap is required. The installer uses
its official `jbctl`, validates all file hashes and hash/file bindings, and stops
on a failed native trust addition. It does not clear global trust or replace
jailbreak components.

The report showed exit127 at `validate-trust-bindings`; its valid trust-cache
header was also rejected. Both locations invoked `awk`. Beta6 uses POSIX shell
builtins there and in the running-process installation guard. Missing-awk,
idempotent configure, failed enumeration, failed addition, tampered files and
incorrect hash/file bindings have explicit host regression coverage. See the
accompanying device-validation file for final package execution results.

## Final package validation

The exact `1006` deb was installed on M2 / iPadOS16.1.1 with Dopamine2.4.8.
Package configuration, file checks and native trust registration passed. Two
Settings-only background/re-entry cycles were followed by a full27 cold boot
in the same App process. Guest SSH22222 and HTTPS returned successfully; a
native iPad screenshot showed the desktop and translucent Apple menu without
colored corruption.

A same-build Hibernate save stopped the original VMM and committed2,684,358,656
bytes. After background/re-entry, a new VMM restored it; authenticated guest
checks confirmed the original boot session, WindowServer and Dock processes,
and working HTTPS. This final-package check did not kill the App; the separately
recorded Beta5 process-death/RAM-continuity acceptance remains historical.

See [the sanitized validation record](2.0.0beta6-device-validation.json) for
artifact hashes, test boundaries and pending device coverage.

## Scope and remaining work

M1/M2 iPads and A16 iPhone14 Pro/ProMax on Dopamine15–16.3.1 remain experimental.
Only M2/iPadOS16.1.1 has local physical-device coverage. The reporter's M1 still
needs a retest. iOS14, rootful and roothide are outside this package's scope.

Physical USB-C ownership transfer, built-in Wi-Fi/Bluetooth assignment, remaining
Settings/Dock icon defects, intermittent stutter and advanced GPU features are
not advertised as completed. Locking pauses the VM; locked Hibernate is still
unavailable. A process killed before a save finishes cannot preserve newer RAM.
See the [current work queue](../2.0.0-current-work-queue.md).

On failure, export Diagnostics and review private content before sharing it.
The original user diagnostic ZIP and device identifiers are not release assets.
