# VirtualMac 2.0.0beta2

构建号及 Debian 版本：`1002`。测试环境：越狱 M2 iPad、iPadOS 16.1.1；
来宾为 macOS Tahoe 26.6.2。macOS 27 指宿主使用的框架版本。

本版独立使用 macOS 27 Virtualization、VMM、PVG/GPU Task 与自有 CPU
兼容后端启动和运行真实来宾，不包含 macOS 13 CPU/VMM 回退。

## 已包含

- 原生来宾图形与 IOSurface 显示、真实来宾鼠标，外接指针拖动和触摸输入。
- 双指滚动、滚动方向设置，以及现有多指输入通路。
- CPU 执行、GIC/计数器和定时器调度优化；重复相同定时请求不再反复提交。
- 原生 virtio 声音输出。来宾识别双声道 48 kHz 默认扬声器，系统声音播放命令成功；
  物理扬声器听感尚未独立验证。麦克风输入暂缓。
- 原生 virtio Ethernet/FileHandle 接入和 libslirp IPv4 NAT。
  实际来宾 DHCP、默认路由、DNS 查询与 Apple 网站 HTTPS 200 均已通过。
- 保留 iPad 回环 `22222` 的永久来宾 SSH 通路。SSH 桥与网卡 NAT 分开工作。
- 登录前校验实际来宾时间并修正大幅偏差；精确 RTC 和持续校时仍待完成。

## 安装

下载 `VirtualMac_2.0.0beta2_1002.deb` 并核对同一 Release 的 `SHA256SUMS`。
先在来宾内正常关机，再退出独立 VirtualMac 应用，以 root 安装：

```sh
dpkg -i /path/to/VirtualMac_2.0.0beta2_1002.deb
```

本包标识为 `com.mac.virtual.independent27`，应用版本为 `2.0.0beta2`。
它接续此前独立 27 测试应用，保留其设置和虚拟机目录。
旧 beta1 的 `com.mac.virtual.v2` 不会被此包替换。不要同时启动两个应用访问同一磁盘。

本包只安装自有应用、独立运行库及发行资料，不附带或改写虚拟机磁盘。
设备需具备当前测试使用的越狱信任能力；包安装会添加自身代码的 trust cache
条目。现有条目的单独撤销未获验证，可能保留至 iPad 重启。
卸载本包不会删除来宾磁盘。

## 已知问题和后续工作

- 冷启动、登录后恢复应用和完整桌面出现仍偏慢，尚未达到此前十几秒的启动体验。
- 图标服务在部分冷请求下仍会崩溃，可能引起图标暂缺或首次加载延迟。
  一次完整桌面截图不代表此问题已解决。
- 暂停/恢复、保存运行状态、GPU 高级能力和其余设备功能继续开发，
  不属于本版完成声明。三指手势的全部物理操作场景仍待验收。
- 网络当前为 IPv4 NAT；IPv6、桥接网络未实现。
- 停用 iPadOS 部分手势需要已有的匹配 SpringBoard 组件；
  本包保留设备现有组件，不会重启或替换 SpringBoard。
- 目前只对上述设备与来宾组合取得实机证据，其它系统组合尚未验证。

## 正式安装包实机复验

已通过实际 `dpkg` 安装及 `1002` 版本登记，包中 265 个应用/运行库文件
与发行清单匹配。正式包实际启动交接成功，四 CPU 与原生 IOSurface 画面推进正常；
永久 SSH、DHCP、DNS 和 HTTPS 200 已复验。一次首帧样本约45秒，
不属于受控性能基准，不能据此宣称启动延迟已解决。

## 源码与重新链接

发布包由 `scripts/development/package-independent27-beta2.py` 从已核验的
独立 App 和 Runtime 候选构建，不使用 beta1 的 Ventura 打包入口。
运行库必须保持与 App 中的 manifest anchor 一致。

`VirtualMac_2.0.0beta2_network-source-and-relink.tar.xz` 包含 libslirp、GLib、
proxy-libintl 对应源码、许可证、配置修正和实际 App 的重新链接输入。
可使用 Xcode 在 Apple Silicon Mac 上运行其中的 `relink.py`，替换兼容的静态库
并重新签名。修改后的应用需要在自己的设备上信任新 CDHash。

设备凭据、来宾磁盘、诊断日志和原始系统固件不进入源码提交。
